# Power BI Project

Open `Ecommerce_Demand_Inventory_Analytics.pbip` with a current version of Power
BI Desktop.

The semantic model embeds its synthetic reporting data, so no local CSV path
remapping is required.

## Report Inventory

- 10 pages
- 81 visuals
- 5 semantic-model tables
- 3 calendar relationships
- 35 DAX measures
- 2023–2025 history and 2026 forecast context

## Pages

1. Executive Overview
2. Demand History
3. Demand Fulfillment
4. Revenue & Margin
5. Inventory Health
6. SKU Performance
7. Category Performance
8. Product Segments
9. Forecast Accuracy
10. History & Forecast

To create a single `.pbix` file, open the `.pbip` file and use **File → Save
As** in Power BI Desktop.

The included `pbip_validation.json` records structural validation results.
