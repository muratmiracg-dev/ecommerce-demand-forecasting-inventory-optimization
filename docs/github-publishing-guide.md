# GitHub Publishing Guide

## Recommended Repository Name

`ecommerce-demand-forecasting-inventory-optimization`

## Recommended Description

End-to-end e-commerce demand forecasting and inventory optimization platform
built with Python, SQL, scikit-learn, Power BI, Excel, and statistical inventory
methods using three years of synthetic fashion retail data.

## Recommended Topics

`demand-forecasting`, `inventory-optimization`, `machine-learning`, `python`,
`sql`, `power-bi`, `excel`, `business-intelligence`, `supply-chain-analytics`,
`retail-analytics`, `time-series`, `data-analytics`, `portfolio-project`

## Upload Method

Use GitHub Desktop or Git from the command line. The PBIP project contains more
than 100 files, so the GitHub web uploader is not the recommended method.

```bash
git init
git add .
git commit -m "Build e-commerce forecasting and inventory optimization platform"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Before running the commands, replace `USERNAME/REPOSITORY` with the repository
created in GitHub.

## LinkedIn Description

Developed an end-to-end e-commerce demand forecasting and inventory optimization
platform using three years of synthetic fashion retail data. Built a
reproducible Python and SQL pipeline covering sales, demand, promotions,
inventory, purchase orders, suppliers, and 60 SKUs across six product
categories. Compared Seasonal Naive, Moving Average, and Gradient Boosting
models through SKU-level backtesting using WAPE, MAE, RMSE, and bias, then
selected a governed champion model for every SKU and generated a 52-week demand
forecast with prediction intervals. Converted forecast uncertainty into
actionable inventory decisions using safety stock, reorder point, EOQ, MOQ, case
pack, service-level, and supplier lead-time constraints. Designed four planning
scenarios—Lean, Base, Growth, and Resilience—to evaluate demand upside, working
capital, and supply-risk trade-offs. Delivered a 10-page Power BI PBIP dashboard,
a 15-sheet Excel scenario planner, a vector HD executive report, and separate
20-slide Turkish and English PowerPoint presentations. The final solution
connects statistical forecasting with practical purchasing decisions and
demonstrates a complete workflow from data generation and model governance to
executive-level business intelligence.
