# Excel Scenario Planner Guide

## Open the Workbook

Open `Excel/Ecommerce_Demand_Inventory_Scenario_Planner.xlsx` with Microsoft
Excel 365 or a recent desktop version of Excel.

## Recommended Workflow

1. Start on **Executive Dashboard** for the portfolio-level result.
2. Open **Scenario Planner**.
3. Select `Lean`, `Base`, `Growth`, or `Resilience` from the scenario dropdown.
4. Review forecast revenue, investment requirement, recommended order units,
   average weeks of supply, SKU action count, and budget status.
5. Use **Replenishment** for SKU-level purchasing priorities.
6. Use **Forecast Accuracy** to inspect champion model governance.
7. Use **Checks** before presenting or sharing the workbook.

## Formula Behavior

The visible scenario outputs reference the selected scenario and source table.
If Excel opens in manual calculation mode, use:

**Formulas → Calculation Options → Automatic**

The workbook was scanned for formula errors before delivery.
